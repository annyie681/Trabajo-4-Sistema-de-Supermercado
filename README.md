# Trabajo-4-Sistema-de-Supermercado
Trabajo 4 para CV - Sistema de Supermercado

Creadores: Hernández Morales Anahí López Corella David Antonio Sandoval López Daniela

Descripción: Es un sistema de venta y administración. Incluye pantallas para iniciar sesión, registrarse y para hacer devolución de ventas, control de inventario, administración de clientes, generación de reportes y creación de respaldos.

Información Adicional: Creado por medio de Canva, utilizando sus herramientas para agregar botones e interactividad entre los distintos escenarios del sistema. Diseñado para poder acceder por usuarios diferentes con distintos permisos.
